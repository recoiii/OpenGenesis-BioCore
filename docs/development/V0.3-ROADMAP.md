# OpenGenesis-BioCore v0.3.0 — Frozen Development Roadmap

Planning baseline frozen on 2026-09-14. Reopen only by explicit project decision.

| Iteration | Name | Primary scope |
|---|---|---|
| 055 | Variant Model & Types | SNV/indel/MNV/DELINS, GT/AD/DP/GQ/PL, coordinate and contig model |
| 056 | VCF Ingestion, Indexing & Normalization | canonical ingestion, random-access index, FASTA-backed normalization |
| 057 | Local Re-alignment & Indel Candidate Calling | gap-aware pileup, local realignment, indel candidates and context evidence |
| 058 | Unified Probabilistic Genotyping | one SNV+indel likelihood/genotype engine |
| 059 | Advanced Variant Filtering | DP/VAF/GQ/MQ, strand bias, homopolymer and regional filters |
| 060 | Variant Prioritization Engine | generic rule engine independent of Annotation 2.0 |
| 061 | Reference Database Framework | versioned local reference DB, GTF/GFF import, interval queries, checksums |
| 062 | Annotation 2.0 Engine | transcript/CDS/codon/protein consequences, MNV/complex awareness |
| 063 | Multi-Sample Matrix Engine | sparse genotype matrix, shared/unique variants and cohort summaries |
| 064 | Case/Control Association | Fisher exact, OR + 95% CI and Benjamini-Hochberg FDR |
| 065 | Variant Analysis Workspace | indexed search, virtualized variant table and interactive filters |
| 066 | Reporting & Export Provenance | TSV/CSV/JSON/VCF plus pipeline/reference/database provenance |
| 067 | Benchmarking & Truth Sets | GIAB and synthetic truth sets, precision/recall/F1/concordance/performance |
| 068 | Release Candidate & v0.3.0 Closure | full cross-platform closure, Gemini + Claude Code, exact SHA and tag |

## Normative dependency rules

- 055 includes MNV and DELINS/COMPLEX from inception.
- 056 is the canonical ingestion boundary and owns coordinate indexing.
- 057 is not done unless BioCore indel output passes 056 normalization without special-case repair.
- 058 owns one unified SNV+indel genotyping abstraction.
- Strand-bias and homopolymer evidence are mandatory parts of the 057/059 path.
- 061 precedes 062; annotation must consume the real reference-database abstraction rather than a temporary store.
- 060 remains a generic rule engine; 062 consequence outputs become additional features later and may not create a circular dependency.
- 064 minimally reports Fisher p, odds ratio, 95% CI and BH-adjusted q values.
- 067 uses external truth data (GIAB where applicable) in addition to synthetic cases.

## Excluded from v0.3

Structural-variant/CNV calling, tumor-normal somatic calling, full GWAS, ACMG clinical classification and distributed/cloud execution are outside this release scope.
